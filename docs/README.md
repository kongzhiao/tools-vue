# 项目文档

本目录记录 `tools-react-yf` 前端的项目规范和当前业务功能。文档以当前代码为准，后端帮助页仅用于补充用户操作说明。

## 推荐阅读顺序

1. [`share/项目概览.md`](share/项目概览.md)
2. [`share/开发规范.md`](share/开发规范.md)
3. [`share/接口规范.md`](share/接口规范.md)
4. [`share/文档规范.md`](share/文档规范.md)
5. [`share/多页签工作区.md`](share/多页签工作区.md)
6. 当前任务对应的功能目录

## 功能目录

- [`系统用户管理/`](系统用户管理/)：后台账号、镇街绑定、角色分配和密码管理。
- [`未救助台账/`](未救助台账/)：未救助明细、应补应退、下放通知、重大疾病编码。
- [`参保台账/`](参保台账/)：年度配置、附件导入、计算、镇街复核和导出。

每个功能目录统一维护 `README.md`、`用户说明.md`、`业务流程图解.md`、`业务数据模型.md` 和 `业务变更增量.md`。

## 维护原则

- 已实现事实以当前前后端代码和数据库迁移为准。
- 两个台账的用户操作可参考后端 `helps/` 下 2026-07-05 版本 HTML。
- 发生业务变化时同步修改前后端对应功能文档，并追加增量记录。
