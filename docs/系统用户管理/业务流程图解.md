# 系统用户管理业务流程图解

## 管理员编辑账号状态

```mermaid
flowchart TD
    A["账户列表显示账号状态"] --> B["编辑用户"]
    B --> C{"当前账号具有管理员身份"}
    C -- "否" --> D["不显示状态编辑项"]
    C -- "是" --> E["选择正常或禁用并保存"]
    E --> F["服务端校验身份和状态值"]
    F --> G["状态变化使原登录失效"]
    G --> H{"保存的状态"}
    H -- "禁用" --> I["禁止登录及会话恢复"]
    H -- "正常" --> J["允许重新登录"]
```

## 最后登录与软删除

- 完成密码登录或 TOTP 登录后，后端更新最后登录 IP 和时间，列表重新查询时回显。
- 删除确认提示“删除后，该账号将无法登录，也无法在账号列表中查询到。”；成功后刷新列表，已删除账号不再展示且原登录失效。

## 登录分流

```mermaid
flowchart TD
    A["输入账号密码"] --> B["POST /api/login"]
    B --> C{"响应状态"}
    C -- "code=0" --> D["保存Token并加载权限菜单"]
    C -- "code=1001" --> E["显示二维码和绑定密钥"]
    E --> F["输入动态验证码完成绑定"]
    F --> D
    C -- "code=1002" --> G["输入TOTP动态验证码"]
    G --> D
    C -- "失败或锁定" --> H["显示错误或剩余锁定时间"]
```

## 会话过期恢复

```mermaid
flowchart TD
    A["业务请求返回可恢复的会话过期状态"] --> B{"当前用户已绑定TOTP"}
    B -- "是" --> C["全局弹出TOTP验证窗口"]
    C --> D["取得新Token"]
    D --> E["重试原请求并保留当前页面状态"]
    B -- "否" --> F["清除登录状态并返回登录页"]
```

## 管理员重置与清锁

```mermaid
flowchart TD
    A["打开账户管理"] --> B{"当前账号有admin_capability"}
    B -- "否" --> C["隐藏安全管理操作"]
    B -- "是" --> D["可设置TOTP要求、重置他人TOTP、清除登录锁"]
    D --> E{"重置TOTP且为生产环境"}
    E -- "是" --> F["输入操作人自己的动态验证码"]
    E -- "否" --> G["直接提交"]
    F --> H["目标用户下次登录重新绑定"]
    G --> H
```
