# 系统用户管理业务变更增量

## 2026-08-23

- 新增：桌面端和移动端登录支持 TOTP 首次绑定与每次登录验证。
- 新增：左下角用户名菜单中的“安全设置”，提供本人首次绑定和修改密码。
- 新增：会话过期后的全局 TOTP 恢复窗口，验证成功后继续原请求。
- 调整：新密码至少 8 位，并同时包含字母和特殊符号；修改成功后完整清理登录状态。
- 新增：账户列表 TOTP 要求、绑定状态和登录锁状态。
- 新增：具备安全管理能力的账号可设置 TOTP 要求、重置他人 TOTP 和清除登录锁。
- 调整：创建用户时“强制开启双重验证”默认选中。
- 保护：“管理员”角色编辑时名称不可修改，删除入口不可用。
- 修正：用户和角色相关操作根据后端返回码决定是否提示成功。

## 2026-07-12

- 新增：建立系统用户管理前端文档基线。
- 确认：系统用户指后台登录账号，不是业务人员数据。
- 确认：支持创建、编辑、删除、角色分配和镇街绑定。
