# 系统用户管理用户说明

## 创建账号

1. 进入“用户管理 → 账户管理”。
2. 点击“创建用户”。
3. 填写用户名、昵称和密码。
4. 如账号只负责一个镇街，选择所属镇街；不选择表示全局账号。
5. 保存后再通过“分配角色”授予所需权限。

用户名必须唯一。创建表单当前只校验非空，密码复杂度应按组织内部安全要求设置，不要使用默认密码或多人共用密码。

## 编辑账号

- 可修改用户名、昵称和所属镇街。
- 密码留空表示保持不变；填写新密码会直接更新该账号密码。
- 修改镇街会影响该账号在未救助通知和参保复核中的数据范围，操作前需确认。

## 分配角色

1. 点击目标账号的“分配角色”。
2. 选择一个或多个角色。
3. 保存后，后端会用本次选择完整替换原角色集合。

角色为空时账号仍可登录，但只能访问无需对应权限的内容。权限变化后如页面未立即更新，退出并重新登录以刷新用户权限缓存。

## 删除账号

删除会移除该账号记录，并通过数据库外键级联清理账号与角色的关联。当前没有回收站，确认账号不再使用后再删除。

## 修改本人密码

从右上角用户菜单打开修改密码，输入原密码、新密码和确认密码。前端要求新密码至少 6 位；修改成功后清理 Token 并重新登录。

## 常见问题

### 为什么看不到超级管理员？

账户列表固定排除 `id = 1` 的超级管理员，这是当前保护规则。

### 为什么账号看不到台账数据？

依次检查账号是否分配了对应查看权限、是否绑定正确镇街、数据是否已经下放，以及当前筛选年份/月度或清算期是否正确。

### 为什么没有启用/禁用按钮？

当前账号模型没有状态字段，系统尚未实现账号启停。不能用删除代替临时禁用，是否新增启停能力需要独立需求和数据库变更。
