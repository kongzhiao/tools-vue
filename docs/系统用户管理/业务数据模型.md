# 系统用户管理业务数据模型（前端）

数据库最终定义见配套后端同名文档。本文件记录页面实际使用的接口模型和边界。

## User

| 字段 | TypeScript 类型 | 必填/默认 | 页面用途 | 边界与安全 |
|---|---|---|---|---|
| `id` | `number` | 返回必有 | 行主键 | 超级管理员 `id=1` 不在列表 |
| `username` | `string` | 创建必填 | 登录名、搜索、列表 | 后端唯一，前端未限制长度 |
| `nickname` | `string` | 页面创建必填 | 显示名 | 后端允许空，前后端校验存在差异 |
| `password` | `string` | 创建必填；编辑可空 | 创建或更新密码 | 不回显、不进入列表、不持久化 |
| `town_id` | `number \| undefined` | 默认空 | 镇街绑定 | 空表示全局账号 |
| `town` | `{id:number; name:string}` | 可空 | 列表显示镇街 | 由后端关联返回 |
| `roles` | `Role[]` | 默认空数组 | 角色标签与分配回显 | 分配保存为完整替换 |
| `created_at` | `string` | 返回 | 创建时间 | 页面本地格式化 |
| `updated_at` | `string` | 返回 | 更新时间 | 当前列表未展示 |

## Role

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | `number` | 角色主键 |
| `name` | `string` | 角色名称 |
| `description` | `string` | 角色说明 |

## 列表参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---:|---|
| `page` | `number` | 1 | 页码 |
| `limit` | `number` | 10 | 每页条数 |
| `keyword` / `search` | `string` | 空 | 用户名或昵称模糊匹配 |
| `role_id` | `number` | 空 | 按角色筛选 |
| `town_id` | `number` | 空 | `0` 表示全局账号，其他值表示镇街 |

返回 `data.list`、`data.total`、`data.page`、`data.limit`。

## 提交模型

### 创建/编辑

```ts
type UserPayload = {
  username: string;
  nickname?: string;
  password?: string;
  town_id?: number | null;
};
```

创建时用户名和密码必须非空；编辑密码为空时前端删除该字段。后端允许质量较弱的输入，页面不得据此宣称存在完整长度或复杂度校验。

### 分配角色

```ts
type AssignRolesPayload = {
  role_ids: number[];
};
```

空数组表示移除全部角色。

## 登录上下文

```ts
type CurrentUser = {
  id: number;
  username: string;
  nickname: string;
  town_id?: number;
  town_name?: string;
  permissions: string[];
};
```

Token 只用于请求认证，不属于可展示业务模型。前端当前保存在 `localStorage`，任何新增功能不得复制到日志、URL、快照或文档。
