# 系统用户管理业务数据模型（前端）

数据库定义见配套后端文档。本文件记录页面使用的主要接口字段。

## User

| 字段 | 类型 | 页面用途 |
|---|---|---|
| `id` | `number` | 用户主键；`1` 为超级管理员 |
| `username` | `string` | 登录名和列表显示 |
| `nickname` | `string` | 显示昵称 |
| `status` | `0 \| 1` | `1` 正常、`0` 禁用；编辑时仅管理员可修改 |
| `last_login_ip` | `string \| null` | 最后成功登录 IP，只读 |
| `last_login_at` | `string \| null` | 最后成功登录时间，只读 |
| `deleted_at` | `string \| null` | 软删除时间；普通列表不返回已删除用户 |
| `password` | `string` | 仅创建或修改时提交，不回显 |
| `town_id` | `number \| null` | 空表示全局账号 |
| `roles` | `Role[]` | 角色标签和分配回显 |
| `totp_required` | `boolean` | 数据库存储的普通用户 TOTP 配置 |
| `totp_effective_required` | `boolean` | 合并超级管理员和“管理员”角色后的实际要求 |
| `totp_bound` | `boolean` | 是否完成 TOTP 绑定 |
| `login_locked` | `boolean` | 当前是否被登录失败机制锁定 |
| `login_lock_remaining_seconds` | `number` | 剩余锁定秒数 |

## CurrentUser

| 字段 | 类型 | 用途 |
|---|---|---|
| `id`,`username`,`nickname` | 基本类型 | 当前登录用户 |
| `status` | `0 \| 1` | 账号状态；禁用时后端拒绝认证 |
| `permissions` | `string[]` | 菜单和按钮权限 |
| `admin_capability` | `boolean` | 是否具有用户安全管理能力 |
| `totp_required` | `boolean` | 是否强制 TOTP |
| `totp_bound` | `boolean` | 是否已绑定 |

前端必须以 `admin_capability` 控制 TOTP 配置、重置和清锁入口；不能只依赖界面角色文案。

## 登录响应状态

| `code` | 前端处理 |
|---:|---|
| `0` | 保存 Token，进入系统 |
| `1001` | 打开 TOTP 首次绑定窗口 |
| `1002` | 打开已绑定 TOTP 验证窗口 |
| `401` | 登录失败或需要重新登录 |
| `40101` | 会话过期，可尝试 TOTP 恢复 |

Token 只用于请求认证，不得复制到日志、URL、页面快照或文档。

## 创建和编辑提交

```ts
type UserPayload = {
  username: string;
  nickname?: string;
  password?: string;
  town_id?: number | null;
  totp_required?: boolean;
  status?: 0 | 1;
};
```

- 创建页面的 `totp_required` 默认 `true`。
- 不具备安全管理能力时前端不允许关闭该配置，后端仍会再次校验。
- 编辑密码为空时不提交密码字段。
- 新账号默认正常；仅编辑用户且具有管理员身份时提交 `status`，后端再次校验身份和值域。
- 状态变化使已有会话失效；禁用不清除角色、镇街和 TOTP 绑定。
- 最后登录信息由服务端在完整登录成功后更新，前端不能编辑；失败与会话续期不更新。
- 删除接口保持 `DELETE /api/users/{id}`，服务端改为软删除并撤销已有会话；不新增恢复入口。
