# 参保台账业务数据模型（前端）

数据库最终结构见配套后端同名文档。本文件记录页面接口模型和状态边界。

## EnrollLedger

| 字段组 | 字段 | 类型/边界 | 页面用途 |
|---|---|---|---|
| 主键 | `id`, `year`, `id_card` | number/string；身份证年度主匹配 | 行标识与导入匹配 |
| 人员 | `name`, `town_name`, `village_name` | 可空字符串 | 列表、筛选、镇街范围 |
| 身份 | `raw_identity` | 可空字符串 | 附件3原始身份 |
| 身份 | `medical_identity_records`, `subsidy_identity_records` | JSON数组 | 保留全部命中身份 |
| 身份 | `medical_identity`, `subsidy_identity` | 可空字符串 | 当前优先身份 |
| 变化 | `included_month`, `cancel_month`, `change_status` | 月份；新增/变更/取消 | 月度变化 |
| 金额 | `resident_payment_amount`, `subsidy_amount`, `tax_first_request_amount` | 两位小数 | 系统来源金额 |
| 税务 | `subsidy_identity_obtained`, `tax_request_batch` | 可空字符串 | 附件5结果 |
| 计算 | `insurance_category` | 空/需核实/档次 | 参保类别 |
| 计算 | `is_insured` | 是/否/待核实/空 | 参保结果 |
| 计算 | `uninsured_reason` | 可空 | 未参保原因 |
| 计算 | `is_eligible_for_subsidy` | 是/否/待核实 | 是否符合资助 |
| 计算 | `is_subsidy_obtained` | 是/否/待核实 | 是否获得资助 |
| 计算 | `subsidy_method` | 系统资助/事后资助/空 | 资助方式 |
| 备注 | `insurance_place_remark`, `death_remark`, `manual_remark` | 可空 | 区外、死亡、人工备注 |
| 镇街填报 | `town_is_insured`, `town_uninsured_reason` | 是/否/空；配置原因 | 镇街核实 |
| 镇街填报 | `town_resident_payment_amount` | 配置内两位小数或空 | 与附件4比对 |
| 镇街填报 | `town_death_time`, `town_remark` | 日期/文本 | 镇街反馈 |
| 填报状态 | `town_submit_status`, `review_status` | 未填报/已填报；未下放/待填报/已填报/已收回 | 复核状态机 |
| 核查 | `payment_amount_check_status` | 未填报/一致/待核查/已核查 | 缴费核查 |
| 批次 | `current_review_batch_id` | number，0表示无当前批次 | 当前下放 |
| 来源 | `last_attachment3_period` 至 `last_attachment6_period` | `YYYY-MM`或空 | 最近导入月份 |

身份证号属于敏感字段，不得写入浏览器存储或日志。金额由后端以两位小数字符串返回，前端展示不得用浮点重新计算业务结果。

## 配置模型

### 身份配置

| 字段 | 类型 | 说明 |
|---|---|---|
| `year` | number | 年度 |
| `config_type` | `subsidy \| medical` | 资助参保/医疗救助 |
| `priority` | number | 越小越优先 |
| `identity_name` | string | 身份名称 |
| `insurance_level` | string? | 参保档次，资助配置使用 |
| `subsidy_standard` | string? | 资助标准 |
| `personal_amount` | decimal | 个人实缴 |
| `subsidy_amount` | decimal | 资助代缴 |
| `included_identities` | string[] | 别名或细分类 |
| `status` | `0 \| 1` | 停用/启用 |
| `remark` | string? | 备注 |

### 身份对应金额

`year`、`special_identity`、`included_identities`、`paid_amount`、`status`、`sort`、`remark`。

### 筛选配置项

未参保原因和居民缴费金额使用通用业务筛选项，页面字段为 `value`、`label`、`sort`、`status`、`remark`。

## 下放批次

```ts
type ReviewBatch = {
  id: number;
  batch_no: string;
  year: number;
  period?: string;
  town_names?: string[];
  dispatch_mode: 'town' | 'manual' | 'filter';
  total_count: number;
  active_count: number;
  pending_count: number;
  filled_count: number;
  recalled_count: number;
  status: '已下放' | '部分收回' | '已收回';
};
```

批次明细状态为待填报、已填报或已收回，并关联对应台账快照展示。

## 导入批次

字段：`uuid`、`year`、`period`、`attachment_type`、`file_name`、`total_rows`、`success_rows`、`failed_rows`、`status`、`message`、时间字段。

附件类型：`attachment3_full_list`、`attachment4_verify`、`attachment5_tax`、`attachment6_death`、`attachment3_return`。

## 查询参数

核心参数：`year`、`keyword`、`town_name`、`change_status`、`medical_identity`、`subsidy_identity`、`insurance_category`、`is_insured`、`is_eligible_for_subsidy`、`is_subsidy_obtained`、`subsidy_method`、`review_status`、`payment_amount_check_status`、`page`、`page_size` 和排序字段。
