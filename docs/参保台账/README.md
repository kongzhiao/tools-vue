# 参保台账

## 功能目标

围绕年度特殊对象资助参保业务，将年度配置、月度全量名单、参保核实、税务请款、死亡名单和人工核对结果汇总为参保台账，并支持镇街下放复核、收回、缴费金额核查和三类导出。

## 页面组成

| 页面 | 路由 | 职责 |
|---|---|---|
| 参保台账明细 | `/enroll/ledgers` | 查询、统计、导入、编辑、下放/收回、核查、导出 |
| 参保配置 | `/enroll/configs` | 年度身份、金额、原因配置和年度克隆 |
| 参保导入记录 | `/enroll/import-batches` | 查看导入批次、成功/失败行数和原因 |

## 数据顺序

1. 维护附件1资助参保身份、附件2医疗救助身份、附件7身份对应明细。
2. 维护未参保原因和居民缴费金额。
3. 导入附件3全量明细，建立当年月度主名单。
4. 按需导入附件4参保核实、附件5税务请款、附件6死亡名单。
5. 如有线下调整，回导附件3人工调整文件。
6. 对需要镇街核实的数据进行下放、填报和收回。
7. 管理员处理缴费金额待核查记录。
8. 导出汇总名单、对比结果或特殊对象资助参保台账。

## 关键规则

- 附件1/2/7是年度配置，附件3/4/5/6是按月业务数据。
- 附件3必须先导入；附件4/5/6和人工回导只更新当年已有身份证。
- 附件3按“年份 + 身份证号”汇总多行身份，并取配置优先级最高项。
- 本年首次出现为新增；身份变化或取消后重新出现为变更；本月全量名单缺失的历史人员为取消。
- 参保类别按资助参保身份、居民缴费金额和资助金额匹配配置。
- 是否符合资助同时校验纳入资助月份、缴费月份、获得资助身份和附件7金额配置。

## 角色

- 管理员：配置、导入、导出、编辑、下放、收回、批次和缴费核查。
- 镇街账号：仅查看本镇街已下放未收回数据，填报参保结果、金额、死亡时间和备注。
- 系统/任务中心：异步导入、计算和导出。

## 主要接口

- `/api/enroll/ledgers`：列表、统计、选项、详情、编辑、删除。
- `/api/enroll/ledgers/import-attachment3|4|5|6`：月度附件导入。
- `/api/enroll/ledgers/import-attachment3-return`：人工调整回导。
- `/api/enroll/ledgers/dispatch|recall`：下放与收回。
- `/api/enroll/ledgers/review-batches*`：下放批次与明细。
- `/api/enroll/ledgers/{id}/payment-check-confirm`：缴费金额核查确认。
- `/api/enroll/ledgers/export`：三类异步导出。
- `/api/enroll/configs`：配置查询、维护、导入和年度克隆。
- `/api/enroll/import-batches`：导入记录。

## 已知边界

- 台账主表按业务逻辑维护年度身份证唯一语义，但迁移只建立普通组合索引，没有数据库唯一约束。
- 页面允许管理员删除台账记录；删除后不可在列表恢复，重新导入是否恢复取决于附件和业务月份。
- 镇街编辑与管理员编辑复用同一接口，后端按账号镇街和下放状态控制可编辑范围。
