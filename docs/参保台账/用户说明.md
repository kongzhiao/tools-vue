# 参保台账用户说明

## 一、维护年度配置

进入“参保台账 → 参保配置”，选择年份后维护：

- 资助参保身份：优先级、身份、参保档次、资助标准、个人实缴、资助代缴、包含身份。
- 医疗救助身份：优先级、身份、包含身份。
- 身份对应明细：特殊人员身份、包含身份、实缴金额。
- 未参保原因：供镇街选择。
- 居民缴费金额：供镇街选择并与附件4比对。

新年度口径相近时可克隆年度配置。覆盖目标年度前必须确认，克隆后抽查金额、优先级和包含身份。

## 二、附件3全量明细

1. 在参保台账明细选择年份和导入月份。
2. 导入附件3 CSV。
3. 到任务中心确认完成，再到“参保导入记录”检查总行数、成功数和失败原因。
4. 核对新增、变更、取消统计，多身份人员应取最优先身份。

附件3是月度全量名单。身份证或身份为空会造成失败或跳过风险，必须先修正文件。

## 三、附件4/5/6和人工回导

- 附件4：写入居民医保缴费金额、区外参保备注并重新计算。
- 附件5：按身份证累计资助金额和第一批请款金额，写入获得资助身份和请款批次。
- 附件6：写入死亡信息，并将参保和资助相关结果调整为否。
- 人工回导：只更新缴费时间、未参保原因、区外备注、死亡备注和人工备注，不新增人员。

这四类导入都必须先有当年附件3台账。

## 四、镇街复核

管理员可按镇街、勾选记录或当前有效筛选条件下放：

1. 下放生成批次，记录变为待填报。
2. 镇街账号只能看到本镇街待填报/已填报且未收回的数据。
3. 镇街填写是否参保、未参保原因、居民缴费金额、死亡时间和备注。
4. 保存后系统重新计算参保类别、资助结果和缴费金额核查状态。
5. 管理员可按批次或勾选记录收回；收回后镇街不可见，需要时可再次下放。

## 五、缴费金额核查

以下情况进入待核查：

- 附件4金额为空但镇街填写了金额。
- 镇街金额与附件4金额不一致。
- 镇街填报参保但没有填写金额。

管理员对照附件4、镇街填报和实际凭证，确认后标记“已核查”并可填写核查说明。

## 六、导出

| 导出文件 | 主要用途 |
|---|---|
| 资助参保对象-汇总名单 | 查看当前筛选台账和动态身份列 |
| 资助参保对象-对比结果 | 核对新增、变更、取消 |
| 特殊对象资助参保台账 | 最终完整业务字段归档 |

镇街账号导出时由后端自动限制为本镇街已下放、未收回的可见数据。

## 常见问题

- “需核实”：身份与金额组合未匹配年度配置，或镇街金额与附件4不一致。
- “是否符合资助=待核实”：缴费时间/纳入时间不完整或缴费金额待核查。
- 身份优先级 9999：附件3身份未命中配置，补充主身份或包含身份后重新导入。
- 镇街无数据：检查下放、收回状态、账号镇街绑定、年份和筛选条件。
