# 多页签工作区

桌面端主框架在面包屑右侧提供多页签工作区，移动端页面不使用该功能。

## 当前行为

- 仪表板以固定首页图标显示在最左侧，不显示文字、不能关闭或拖动。
- 打开菜单页面时新增对应页签；页签使用所属左侧菜单模块的图标。
- 切换页签只切换已挂载的页面实例，不重新加载页面数据；关闭页签或执行“刷新当前页签”时才销毁对应实例。
- 已打开页签、排列顺序、页签 URL 和当前选中项按用户编号写入浏览器本地存储，刷新浏览器后恢复。
- 非首页页签支持按住并左右拖动调整顺序，调整后的顺序随页签状态持久化。
- 右键菜单提供刷新、关闭当前、关闭左侧、关闭右侧、关闭其他和关闭全部操作；“关闭全部”保留固定首页图标。
- 页签超过可用宽度时继续保持单行，左右两侧显示滚动箭头；点击箭头横向查看页签，切换页签时自动将当前项滚动到可见区域。

## 实现位置

- 主组件：`src/components/WorkspaceTabs/index.tsx`
- 样式：`src/components/WorkspaceTabs/index.less`
- 布局接入：`src/app.ts` 的 `childrenRender`

工作区通过 `useOutlet()` 缓存路由已经解析出的页面实例，而不是缓存会跟随全局路由变化的 `Outlet` 占位符。页面若监听全局路由参数，也应先确认自身处于当前路由，避免页面隐藏期间因其他页签的 URL 变化重新请求数据。
