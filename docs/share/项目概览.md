# 项目概览

## 项目定位

`tools-react-yf` 是共享救助信息服务平台的管理端前端，面向医保业务管理员和绑定镇街的业务账号。系统围绕 CSV 数据导入、筛选、匹配、筛查、统计、复核和导出提供操作界面。

配套后端为同级目录 `tools-hyperf-yf`。前端不持有最终业务规则，金额、身份、状态和数据范围均以后端返回为准。

## 技术架构

```text
Umi 路由与 access
        ↓
React 页面 + Ant Design 组件
        ↓
src/services 或 Umi request
        ↓
Authorization: Bearer Token
        ↓
tools-hyperf-yf /api
        ↓
同步 JSON 或异步任务中心
```

主要技术：React 18、TypeScript、Umi Max 4、Ant Design 5、Day.js。项目通过 `.umirc.ts` 注册固定路由，通过 `src/access.ts` 将后端权限名称映射为页面和按钮权限。

## 用户与数据边界

- 全局账号：`town_id` 为空，可按授权访问全局业务数据。
- 镇街账号：绑定一个镇街；未救助通知和参保复核由后端限制为本镇街可见数据。
- 超级管理员：当前前端以用户名 `admin`、昵称“超级管理员”或 `*` 权限识别；最终权限仍以后端为准。
- 系统用户是后台登录账号，不等同于台账内的参保人、救助对象或患者。

## 当前重点模块

### 系统用户管理

支持后台账号列表、用户名/昵称搜索、角色和镇街筛选、创建、编辑、删除、角色分配、登录与本人修改密码。当前用户表没有启停状态字段。

### 未救助台账

- 未救助明细：附件1、附件2、独立筛查、筛选和导出。
- 应补应退明细：附件4、附件2、独立专项筛查和导出。
- 下放通知：导入通知明细、按镇街下放、接收、通知、反馈、备注、报销标记和导出。
- 重大疾病编码：维护与 CSV 导入。

### 参保台账

- 参保配置：资助参保身份、医疗救助身份、身份对应明细、未参保原因、居民缴费金额及年度克隆。
- 参保台账明细：附件3/4/5/6 与人工调整回导、筛选、统计、编辑、下放复核、收回、缴费核查和三类导出。
- 参保导入记录：查看异步导入批次和结果。

## CSV 与任务中心

两个台账当前只接受 CSV，后端自动识别 UTF-8、GBK 和 GB18030。导入、筛查和导出通常返回任务 UUID，前端任务中心持续展示进度、完成文件或失败原因。提交成功只代表任务已入队，用户必须核验任务最终状态。

## 当前接口现状

项目尚未形成完全统一的响应码：大多数业务接口成功为 `code = 0`，任务接口成功为 `code = 200`；提示字段同时存在 `msg` 和 `message`。前端现阶段必须兼容，具体见 [`接口规范.md`](接口规范.md)。
